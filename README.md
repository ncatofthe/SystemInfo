# SystemInfo

PowerShell-скрипт для быстрого сбора информации о Windows 10/11 компьютере.

Скрипт помогает при диагностике, инвентаризации и поддержке пользователей: собирает ключевые сведения о системе и сохраняет результат в текстовый файл.

## Возможности

- сбор информации о системе Windows;
- работа через WMI;
- запуск без прав администратора;
- сохранение отчета в файл;
- подходит для первичной диагностики рабочих станций.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\SystemInfo.ps1
```

## Стек

PowerShell, WMI, Windows.
